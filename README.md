# 🔎 Reconnaissance, Footprinting & Enumeration Project

This project focuses on the information gathering phase of penetration testing, including reconnaissance, footprinting, and enumeration techniques used to identify systems, services, and potential vulnerabilities.

---

# 🎯 Objectives

- Learn passive and active reconnaissance
- Understand enumeration techniques
- Discover network services and targets
- Analyze exposed infrastructure

---

# 🧰 Tools Used

- Nmap
- Whois
- DNSRecon
- Netdiscover
- Wireshark
- theHarvester

---

# 🔍 Topics Covered

- Passive Reconnaissance
- Active Reconnaissance
- DNS Enumeration
- Port Scanning
- Service Detection
- SMB Enumeration
- SNMP Enumeration

---

| System | Purpose |

| Vulnerable Machines | Targets |
